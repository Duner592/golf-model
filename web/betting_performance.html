Calculation notes

Settled mode preserves Tournament P/L conventions: pending outcomes and rows without a usable date or profit figure are excluded; recorded Profit/Loss takes priority, with return minus stake as fallback. Include pending preserves ROI conventions: all source rows contribute recorded returns and stakes, including undated rows. ROI is P/L divided by stake. Period tables omit undated rows; the cards retain them in include-pending mode. Weekly labels keep the previous calendar-year / ISO-week grouping. Tournament search previously recalculated running totals; here it only hides rows so the cumulative timeline stays consistent.
